# Research Topics

- Open-weight model comparison
- Quantization trade-offs
- Context-window behavior
- KV-cache and concurrency effects
- Structured JSON generation
- Tool calling
- Agent reliability
- Retrieval-augmented generation
- Embeddings and semantic search
- Local versus hosted inference
- GPU memory planning
- Prompt/version evaluation
- Latency and throughput benchmarking
- AI-assisted software engineering
- LLM API gateways
- Human approval and safe automation

Each topic should produce a reproducible experiment rather than only a narrative conclusion.
