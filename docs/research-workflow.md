# AI/LLM Research Workflow

A reproducible workflow for practical AI and LLM research.

## Workflow

**Question → Hypothesis → Environment → Experiment → Measure → Compare → Document → Reproduce**

Separate measured results from assumptions and opinions.

## Environment record

Record model identifier, model format/quantization, runtime, hardware class, context length, sampling parameters, prompt version, software versions, and date.

## Reproducibility

Keep prompts, test cases, configuration, and evaluation criteria versioned. Avoid relying on undocumented UI behavior.

## Research boundary

The purpose is to understand systems and produce original implementations. Check licenses and model terms before redistribution or commercial use.
